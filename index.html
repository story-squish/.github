Features

Plan it, draft it, keep it straight.

Everything a novel needs between the first index card and the last revision, without a cloud account.

Scene cards

Title, summary, status, act, POV character, location and story day on every card. Reorder by drag or keyboard; search covers prose too, with filters by status, act and POV.

  • Outline
  • Draft
  • Revision
  • Final
  • Archived

Chapters

Tick Starts a chapter on a scene and the chapter runs until the next one. Cards show the number; exports gain headings.

Write & Zen

A prose editor per scene with previous/next navigation, scene and manuscript word counts, and a distraction-free Zen mode.

Story calendar

Date scenes and days number themselves. Set a Day 0 scene and the rest read “3 months after” or “2 days before”.

Relationships

A graph of directed, labelled relationships between characters, alongside roles, goals, notes and locations.

Undo everything

Undo and redo across every board edit, including reloads and restores. Deletes ask first and tell you what goes with them.

Light and dark

Ten color schemes from Parchment to Forest Night, each checked for readable contrast.

Spellcheck and thesaurus

Right-click for suggestions and synonyms. English (US, UK) built in; German, Spanish, French and Russian download on first use, and any installed Hunspell dictionary works. Character and location names always count as correct. On macOS, Auto follows your keyboard layout.

  • EN
  • DE

  • + Hunspell

Export

Outline or full manuscript as Markdown, with chapter headings. Import and export the whole board as JSON.

One board per novel

Each novel lives in its own file, named after its title. Switch between recent boards offline, or open one from the cloud.

Your work

Your novel lives in files you can see.

No account and no lock-in. The board is a JSON file on your disk, saved after every change and copied into rolling backups beside it.

  • Crash-safe saves. Every write goes to a temp file first, then replaces the board in one step.
  • Rolling backups. The newest 30 copies are kept, and imports and restores save a tagged copy first.
  • Sync with anything. Put the board in iCloud Drive, Dropbox, OneDrive or Syncthing. Changes from other machines load within seconds, and conflicts are kept, not overwritten.
  • Off-site history. Optional backup to a private GitHub repository, pushed a few seconds after you stop typing. Every version can be restored.

Install

Get StorySquish.

Free for every platform.

Homebrew

brew tap meslab/tap
brew trust --cask meslab/tap/storysquish
brew install --cask storysquish

Upgrade later with brew upgrade --cask storysquish.

Installer package

A universal .pkg for Apple silicon and Intel that installs StorySquish.app into Applications.

Download for macOS

The package isn't notarized, so macOS blocks it the first time. Allow it in System Settings → Privacy & Security → Open Anyway.

Standalone executable

A zip with a single StorySquish.exe. No installer and no Visual C++ runtime needed: unzip it anywhere and run it.

Download for Windows

SmartScreen may ask you to confirm the first time.

Homebrew

The formula builds from source.

brew tap meslab/tap
brew trust --formula meslab/tap/storysquish
brew install --formula storysquish

System libraries

Needed when building yourself on Debian or Ubuntu.

sudo apt-get install libxcb-render0-dev libxcb-shape0-dev \
  libxcb-xfixes0-dev libxkbcommon-dev libssl-dev

Cargo

git clone https://github.com/story-squish/storysquish
cd storysquish
cargo run -r                       # default board
cargo run -r -- path/to/board.json # a specific board
make install                       # release build for this OS

make install puts the app in /Applications on macOS, or ~/.local/bin with a launcher entry on Linux.
